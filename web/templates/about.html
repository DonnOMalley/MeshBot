About {{ bot_name }}

{{ bot_name }} is a configurable Meshtastic channel bot that connects to a device via USB serial, monitors a mesh network channel, responds to commands, tracks active nodes, logs chat history, and exposes this multi-page web dashboard for monitoring, messaging, and device inspection.

The bot listens for commands prefixed with ! on the configured channel (e.g. !ping ) and accepts the same commands via direct message. Outgoing web messages are prefixed with the sender’s short name so other mesh nodes can identify the source.

Command Reference
Command Syntax Description
!hello !hello Sends a greeting reply to the sender.
!ping !ping Responds with a pong — useful for testing reachability.
!test !test Reports the hop count to reach the bot ( Hops: N 🐇 ), or confirms a direct connection when there are no relays.
!last !last <N> <CHANNEL> Returns the last N messages from the specified channel as DMs (max 5). N must be a positive integer; CHANNEL is the channel name.
!trace !trace Initiates a traceroute from the bot back to the sender, reporting each hop, SNR readings (forward and return), and total round-trip duration.
!web !web Replies with the URL of this web dashboard so any mesh node can find the portal.
!cmdList !cmdList Sends a direct message listing all available commands.
!joke !joke Fetches a joke from JokeAPI and replies with it. Falls back to a local cache when offline. user command

Usage Notes

All commands use the ! prefix (e.g. !ping ). Commands can be sent on either the monitored channel or via direct message to the bot.

{% if case_sensitive %} This bot is currently running in case-sensitive mode. Commands must be typed with exact capitalisation — !Ping and !PING will not be recognised. {% else %} This bot is currently running in case-insensitive mode. Commands are matched regardless of capitalisation — !ping , !Ping , and !PING are all equivalent. {% endif %}

To test commands without a physical Meshtastic radio, use the Bot Test page. It runs a live DM session in the browser and supports all commands including quick-send buttons for the most common ones.
