About {{ bot_name }}

{{ bot_name }} is a configurable Meshtastic channel bot that monitors a mesh network channel via serial connection, responds to commands, tracks active nodes, logs chat history, and exposes this web dashboard for monitoring and messaging.

The bot listens for commands prefixed with ! on the configured channel (e.g. !ping), and also accepts the same commands via direct message.

Source code and documentation: {{ github_url }}

Command Reference
Command Syntax Description
!hello !hello Sends a greeting reply to the sender.
!ping !ping Responds with a pong — useful for testing reachability.
!test !test Reports the hop count to reach the bot (Hops: N 🐇), or confirms a direct connection when there are no relays.
!last !last <N> <CHANNEL> Returns the last N messages from the specified channel. N must be a positive integer; CHANNEL is the channel name.
!trace !trace Initiates a traceroute from the bot node back to the sender, reporting each hop, signal-to-noise ratio readings, and total round-trip duration.
!web !web Replies with the URL of the web dashboard so any mesh node can find the portal.
!cmdList !cmdList Sends a direct message to the requester listing all available commands.
Usage Notes

All commands use the ! prefix (e.g. !ping). Commands can be sent on any monitored channel or via direct message to the bot.
